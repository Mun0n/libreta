# Poner Sopa de letras en el iPad

Hace falta internet solo la primera vez.

1. Abre Safari y entra en la dirección de Sopa de letras.
2. Pulsa el botón compartir (el cuadrado con la flecha).
3. Elige **Añadir a pantalla de inicio**.
4. Pulsa **Añadir**.

A partir de ahí se abre como una app, sin barra del navegador, y sigue funcionando sin conexión.

Si las letras se ven pequeñas: en la pantalla de inicio, **Ajustes**, y elige **Letras muy grandes**.
